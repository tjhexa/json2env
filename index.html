Conversion rules

Predictable flattening.
Clean round-trips.

Three rules cover 95% of real configs. Arrays of objects use numeric segments — everything else stays human-readable.

01

Nesting becomes UPPER_SNAKE

{ "db": { "host": "x" } } flattens to DB_HOST=x. Back-conversion splits on _ and lowercases each segment.

{
  "cache": { "ttl": 60 }
}
→ CACHE_TTL=60

02

Simple arrays join

["auth","api"] becomes FEATURES=auth,api and parses back with auto-typed items.

03

Types are preserved

true, integers, and empty values round-trip. null and "" write as an empty assignment.
